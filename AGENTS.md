# SakhiSetu Engineering Guidelines

This repository contains the production code for SakhiSetu — an offline-first AI bookkeeping Progressive Web Application for Women's Self-Help Groups (SHGs) in rural India.

## Development Commands
- `npm run dev`: Start local development server
- `npm run build`: Production build with Vite and TanStack Router
- `npx tsc --noEmit`: Run TypeScript static type checking
